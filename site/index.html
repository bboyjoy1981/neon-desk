每个模块，各司其职。

实时信号

约每 2 秒更新系统指标，查看最近 60 秒 CPU 曲线。驱动未提供数据时显示不可用，不用虚构读数填满仪表。

全盘雷达

覆盖已就绪固定盘与可移动盘，定位大目录。访问失败、链接和扫描上限会明确标记。

缓存清理

以精确规则识别候选缓存，显示软件、路径、文件数与保留期。默认不选择，执行前再次确认。

重复与大文件

大文件雷达寻找 ≥100 MB 文件；重复分析对 ≥1 MB 同体积文件做 SHA-256 校验。结果只读，不自动删除副本。

空间增长

比较前后扫描基线，定位悄悄增长的软件目录。扫描不完整时不计算增长。

本地记录

扫描与清理摘要保存在本机，并限制保留数量。工具不要求第三方账号，不上传扫描结果。

扫描不是删除。

  1. 启动全盘扫描，统计目录占用、已识别应用与白名单缓存。
  2. 进入缓存清理，核对具体路径和保留规则。
  3. 退出对应软件后重新扫描，勾选需要清理的候选项。
  4. 确认后逐文件执行，变化、占用或不可访问的文件会跳过。

确认清理后为永久删除。取消只能停止后续操作。聊天、文档、草稿、数据库与未知大文件不会因为名称里有 cache 就被加入删除范围。

接入你的 Windows。

预览阶段，支持 Windows 10/11 x64。开发需要 .NET 10 SDK；轻量发布包运行需要 .NET 10 Windows Desktop Runtime。

dotnet restore NeonDesk.csproj
dotnet run --project NeonDesk.csproj
dotnet publish NeonDesk.csproj -c Release --self-contained false -o publish
